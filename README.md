One line about the universal bedtime paradox: you turn the lights off to sleep early, and instead of sleeping you lie awake in the dark while your brain pulls an unpaid night shift — negotiating like it owes you back pay. Everyone has lived it: the lights go out, the thoughts clock in.

Run it with:

```sh
node main.ts
```

Output:

```
I turned the lights off to sleep early, then lay awake in the dark negotiating with my brain like it owed me back pay.
```
